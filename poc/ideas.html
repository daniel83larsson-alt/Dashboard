Problemet idag

Tre saker som saknas i varje integrationsleverans

🔭

Kunden ser ingenting

När integrationen är levererad vet kunden inte om den fungerar, hur mycket som flödar, eller när något gått fel. Allt ansvar hamnar på er att bevaka.

📋

Spec-arbetet tar för lång tid

Mappningsdokument byggs manuellt i Excel eller Word. Samma information skrivs om flera gånger – i spec, i kod, i dokumentation. Tidskrävande och felkänsligt.

📞

Support utan verktyg

Felsökning kräver att teamet loggar in på servrar och gräver i loggar. Kunden ringer och frågar – men det finns ingen dashboard att peka på.

Modul 3 · Idé #11

Mapping Spec Tool

Ladda upp in- och utfil. AI auto-mappar de enkla fälten. Du fyller i resten. Resultatet blir färdig spec, dokumentation och förklaring för kunden – allt i ett.

Genererat underlag:

// Genererad mappning – iCore Spec v1.2
"order_id" → "OrderNumber" // Direkt mappning
"customer_no" → "CustomerID" // Direkt mappning
"delivery_date" → "ExpectedDelivery" // Format: yyyy-MM-dd
"warehouse_ref" → "ReferenceCode" // ⚠ Manuell verifiering
📤

Ladda upp in & ut

JSON, XML, CSV eller Excel. Verktyget läser strukturen och föreslår mappningar automatiskt.

🧠

AI auto-mappar

"order_id" → "OrderNumber" hittas automatiskt. Oklara fält flaggas för manuell granskning.

📄

Spec & dokumentation

Export som PDF, Word eller HTML. Kan direkt skickas till kund för godkännande och signoff.

🔍

Förklarar för kunden

Kunden kan se exakt hur deras data mappas. Bygger förtroende och minskar missförstånd i kravfasen.

⏱️
Sparar tid i varje leveransprojekt Mappningsdokumentation som tog 1–2 dagar tar nu timmar. Kan säljas som fristående verktyg eller ingå i portalen.

Tillägg — Grupp 4

SaaS-funktioner att lägga på portalen

Dessa kan aktiveras per kund och skapar recurring revenue utan extra leveransarbete.

🏪

Integration Marketplace

Katalog med färdiga integrationer att beställa direkt. Kunden väljer "Koppla WMS till Fortnox" – ni levererar. Säljer integration som produkt, inte som projekt.

Ny affärsmodell
📊

Automatiska SLA-rapporter

Varje månad skickas en PDF till kunden: uptime, volymer, lyckade/misslyckade körningar. Visar konkret värdet av integrationen. Enkelt att bygga, högt upplevt värde.

Automated
🔔

Alerting & Notifikationer

Kunden sätter egna regler: "Om ingen order kommit in på 2 timmar – skicka SMS till mig". Proaktiv övervakning som kunden konfigurerar själv via portalen.

Self-service
🗺️

Integration Canvas

Visuellt diagram: vilka system är kopplade, vad flödar mellan dem. Klicka på en koppling och se detaljer. Används i kundmöten och som säljmaterial för nya kunder.
